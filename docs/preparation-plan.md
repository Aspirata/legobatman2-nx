# Подготовка LEGO Batman 2 для Switch

Дата: 2026-11-13. Пользователь поручил подготовить репозиторий, пока копируется игра.

## Объём этой стадии

Подготовить воспроизводимые инструменты на Python 3.11+ без внешних зависимостей.
Не создавать фиктивный NRO, игровые адреса, список поддерживаемых версий или обещания FPS.

1. Написать проверки на синтетических XEX2: чтение big-endian полей, SHA-256,
   неверная сигнатура, обрезанные таблицы, неверные смещения, повторяющиеся ключи.
2. Реализовать `tools/project.py inspect-xex PATH`: только чтение открытого заголовка,
   потоковое хеширование файла, JSON в stdout. Это не дешифратор и не рекомпилятор.
3. Добавить `doctor`: наличие инструментов в PATH и компонентов DEVKITPRO;
   явно различать обнаружение файлов и успешную сборку.
4. Оформить README, исследование исходных проектов, этапы переноса, исключения Git,
   CI для подготовительных инструментов на Windows и Linux.
5. Выполнить тесты, обе команды и проверку diff. Игровую сборку проверить после
   получения default.xex и настройки отдельной среды сборки.

## Проверки риска

- ISO вместо XEX: понятная ошибка без попытки прочитать весь образ в память.
- Смещения за пределами заголовка и большие счётчики: отказ до чтения.
- Отсутствующий execution-info: unknown, без угадывания версии игры.
- Путь с пробелами и Unicode: поддерживается.
- Отсутствующий SDK: doctor сообщает missing, не объявляет среду готовой.
