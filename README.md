# legobatman2-nx

LEGO Batman 2: DC Super Heroes — подготовка статической рекомпиляции Xbox 360 → Nintendo Switch.

**Состояние: подготовительные инструменты. Игра ещё не рекомпилирована, запускаемого NRO нет.**
Целевая платформа — оригинальный Switch / Lite / OLED: ARM64, libnx и deko3d.
Файлы игры пользователь предоставляет отдельно; они не входят в репозиторий.

## Что уже работает

- Анализ открытого заголовка `default.xex`: SHA-256, Title ID, Media ID, версия,
  точка входа и базовый адрес, если поля присутствуют.
- Проверка наличия инструментов сборки без установки и изменения системы.
- Автотесты на синтетических данных, workflow для Windows и Linux.
- [Исследование и этапы переноса](docs/porting.md), [подготовка окружения](docs/setup.md),
  [задание для продолжения работы](docs/codex-task.md).
- [Анализ предоставленного образа и подробный план первого рабочего билда](docs/first-working-build.md):
  подтверждённые метаданные игры, 12 задач, зависимости, риски и критерии проверки.

## Быстрый старт

Нужен Python 3.11 или новее, без дополнительных пакетов. Из корня репозитория:

```powershell
python tools/project.py doctor
python -m unittest discover -s tests -v
```

Когда игра полностью скопирована и распакована:

```powershell
python tools/project.py inspect-xex "D:/Games/LEGO Batman 2/default.xex"
```

Команда читает файл и печатает JSON. Она не распаковывает ISO, не дешифрует код,
не проверяет подпись и не подтверждает совместимость игры с будущим портом.
Title ID и хеш фиксируются по реальному файлу: поддерживаемая версия пока не выбрана.
Игру можно хранить вне проекта либо в игнорируемой папке `game/`.

## Основа

[ReXGlue](https://github.com/rexglue/rexglue-sdk) — перевод PowerPC в C++ и среда исполнения.
[LEGO Batman](https://github.com/surblazer/legobatman-recomp) — ориентир по TT-движку,
сборке Switch и deko3d за обработчиком команд Xenos.
[Sonic Adventure 2](https://github.com/ChanseyIsTheBest/sa2-nx) — ориентир по прямому
перехвату Direct3D, deko3d и измеряемым оптимизациям.

Это источники для изучения, а не уже подключённые зависимости.
Снимки версий записаны в [references.json](references.json); локальные копии в
`third_party/` исключены из Git. Их код пока не включён в этот проект.

## Ближайшая контрольная точка

После получения игры: определить сборку XEX и XDK, настроить SDK, получить первый
кодген и диагностический запуск на ПК. Затем переносить на Switch с deko3d,
сравнивая изображение и поведение с эталоном. Цель производительности для начала —
проверить возможность стабильных 30 FPS на штатных частотах; это не обещание результата.
60 FPS и повышение разрешения оцениваются после замеров и проверки игровой логики.
